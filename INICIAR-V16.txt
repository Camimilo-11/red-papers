Extraiga este ZIP en una carpeta nueva. Abra la carpeta del proyecto SIMAPC en VS Code. Detenga el servidor anterior con Ctrl+C. En la terminal de esta carpeta ejecute npm.cmd install y luego npm.cmd run dev. Abra la dirección que indique la terminal y recargue con Ctrl+F5. No mezcle src con versiones anteriores. Esta versión mantiene los datos de muestra.
